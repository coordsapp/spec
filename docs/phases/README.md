# Phases

These are the engineering phases for the Coords Cloud / hosted SaaS build (spec + core + cloud). They are unrelated to Landblock's own adoption stages (see `cloud/docs/landblock-overview.md`) — Landblock deliberately uses the word "Stage," not "Phase," so the two numbering schemes never collide in conversation.
